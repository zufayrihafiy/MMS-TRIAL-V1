Firebase Authentication Setup Guide

Staff ID + Password Secure Backend Integration

Follow these 5 steps to configure real Firebase Authentication with Staff ID mapping for production:

1
Create Firebase Project
Open Firebase Console, create a new project named mms-plant-ops, and open Project Settings.
2
Enable Email/Password Sign-In
In Firebase Console, go to Build → Authentication → Sign-in method. Enable Email/Password provider.
3
Create Staff Accounts
Go to the Users tab in Firebase Authentication. Add users using the mapped domain (e.g. pn001@mms.internal or usr-01@mms.internal). Set a strong password for each user.
4
Add Netlify Environment Variables
In your Netlify Dashboard → Site configuration → Environment variables, add:
FIREBASE_WEB_API_KEY = (Your Web API Key from Firebase Project Settings) FIREBASE_PROJECT_ID = (Your Firebase Project ID) FIREBASE_STAFF_DOMAIN = mms.internal FIREBASE_ADMIN_STAFF_IDS = USR-01,PN001 GOOGLE_APPS_SCRIPT_URL = (Your Apps Script Web App URL)
5
Deploy & Log In
Trigger a Netlify deployment. Enter Staff ID (e.g. PN001) and the configured password. The backend function will authenticate against Firebase and issue a secure JWT session.
